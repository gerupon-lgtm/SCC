# 鐘の音（WAV）

SCC（K051649）の計算で作った鐘の音です。試作ページ `bell.html` と同じ計算を、`node tools/render-bell.js` でファイルに書き出しました。

| ファイル | 音色 | 高さ | 鳴っている長さ |
| --- | --- | --- | --- |
| `small-C4.wav` | 小さな鐘 | C4（約261.6Hz） | 約2.5秒 |
| `church-C4.wav` | 教会の鐘 | C4（約261.6Hz） | 約2.9秒 |

- 形式：48,000Hz・16ビット・モノラル・3.0秒（鳴り終わった後は無音）
- 大きさ：最大の振れ幅を -1dBFS にそろえています。2つの音の大きさの差は、そろえた分だけ元と違います
- 直流除去（10Hz）だけをかけています。アプリと同じです
- 音色の設定値は `docs/bell.md` と `src/bell/bell-voice.js` の `BELL_PRESETS`。ほかの高さが要るときは、`tools/render-bell.js` の `NOTE` を変えて書き出せます
- MAMEの動きにそろえた計算を使っています。ライセンス表示は `NOTICE` を見てください
