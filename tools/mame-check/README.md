# MAMEとの照合（T-006 案A）

MAMEの `k051649.cpp`・`k051649.h`（`mame/`、変更なし）を、小さな枠（`shim/emu.h`）で動かし、出力を記録します。
基準版（`src/core/scc-ref.js`）の出力と、1クロックずつ完全一致で比べます。

## なぜこの形か

MAMEのチップ部分は、MAME本体の仕組み（デバイス・音声ストリーム・アドレスの割り当て）に依存しています。
そこで、計算の部分には手を入れず、依存先だけを最小の代用品に置き換えました。読み違いの入る余地を減らすためです。

- `add_int(ch, i, v, 1024)` は、割り算の前の整数 `v` の和を記録します（基準版と同じく整数で比べるため）
- アドレスの割り当ては、MAMEの `scc_map` をそのまま実行して記録し、その表で書き込み先を決めます
- テストレジスタ（0xE0〜）は書きません。MVPでは動きを再現しない【設計】ためです

## 手順（Windows、Visual Studio Build Tools が必要）

```
tools\mame-check\build.bat
node tools/mame-check/record.js
node --test
```

`record.js` は `tests/fixtures/mame/` に、操作列（`.ops`）とMAMEの出力（`.out`、「値 回数」の行）を書き出します。
記録済みのファイルがあれば、テストにコンパイラーは要りません。

## 記録した条件

| 名前 | シード | 内容 |
| --- | --- | --- |
| random-1 / random-2 | 1 / 20261010 | 周波数・音量・キー・波形・鏡・何もないアドレスへの書き込みを無作為に |
| low-1 / low-2 | 7 / 99 | 周波数を 0〜40 付近に寄せる（止まる境界 8/9 と、最も速い周波数） |
