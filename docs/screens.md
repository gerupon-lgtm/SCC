# 画面定義

画面は1つです（単一ページ）。モバイルを主とし、PCでは横に広げます。

## デザイントークン

- 決定（2026-10-15、発案者が3種を実画面で比べて B を選んだ）：`font-family: "BIZ UDPGothic", "Noto Sans JP", "Noto Sans CJK JP", "Hiragino Sans", system-ui, sans-serif;`（OS標準のみ。配信なし）。BIZ UDPゴシックは Windows 標準。Android・iOS には無いので、OS標準の日本語書体になる
- 【想定】数値表示（周波数など）：`ui-monospace, "SF Mono", Menlo, Consolas, monospace`
- 【想定】ウェイト：400と600。基準サイズ16px、行間1.5
- 【想定】アイコン：ライブラリを使わず、文字（▶ ■ など）で表す。混在は禁止
- 色は、CSSの変数で1か所に集める（暗い背景【想定】）。変更はA区分
- 見直し：実画面で3種（A：OS標準、B：UDゴシック系、C：等幅）を比べ、B に決めた（T-012 完了）

## 画面の構成（上から）

1. **ヘッダー**：名称（仮称）、バージョン
2. **開始ボタン**：「音を出す」。押すまで他の操作は無効。押した後は「止める」
3. **状態表示**：音の状態、MIDIの状態（4種）、音切れの表示
4. **音量**：スライダー（0〜1、初期0.3）
5. **波形の選択**：プリセット5種
6. **チャンネル表示**：チャンネルごとに、周波数・音量・キー・波形のバンク
5.4 **パート**（F-015、0.8.0〜）：パート1〜8（MIDI チャンネル1〜8）の波形を選ぶ。パート1は波形ボタン・画面の鍵盤と同じ。選んだ波形は覚えておく（自作の波形そのものは覚えない）。10 は PSG のドラムと表示する。チャンネル表に「パート」の列
5.5 **波形エディター**（F-007、0.7.0〜）：32点をなぞって描く。「今の波形を写す」「なめらかに」「上下を反転」「0にする」、@s と同じ16進の文字の出し入れ。保存しない
7. **画面の鍵盤**：外部機器がなくても弾ける。タッチ対応、2オクターブ、オクターブ移動
8. **フッター**：ライセンス表示へのリンク

## 状態ごとの表示

| 状況 | 表示 |
| --- | --- |
| 開始前 | 鍵盤・音量は無効、開始ボタンだけ有効 |
| MIDI非対応・拒否・機器なし | 状態欄に案内。画面の鍵盤で弾ける |
| 音切れ | 状態欄に印。操作は続けられる |
| 画面が狭い（360px幅） | 縦に積む。横スクロールなし |

## 遷移

なし（単一ページ）。出口：「止める」で音を止め、開始前の状態に戻る。
