# 性能の記録（T-013）

## 測り方

- `node tools/bench.js`：全チャンネルを鳴らし、48,000Hzで5秒分の音を作る時間を測ります（変換・後処理を含む）
- 値は「実時間に対する処理時間の割合」です。100%を超えると、実時間に間に合わず音が切れます
- ブラウザでは、画面の「処理の重さ」に、同じ意味の値が出ます（Worklet の中で `Date.now()` を使って平均。ミリ秒単位なので粗い目安です）
