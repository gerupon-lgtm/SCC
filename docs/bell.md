# 鐘の音の試作（T-201）

本体（`index.html`）とは別のページです：`bell.html`（公開：https://gerupon-lgtm.github.io/SCC/bell.html ）。
発案者が、鐘の音（単音）を別のアプリで使うための試作です。本体のコードは変えていません。

## なぜこの作りか

- **1チャンネルでは作れない**：SCCの1チャンネルは、32点の波形のくり返しです。くり返しの波には、基準の高さの整数倍の音しか含まれません。鐘らしさは、整数倍でない高さの音（例：1.2倍）が混ざることから来るので、チャンネルを重ねます
- **整数倍の音は1つの波形にまとめる**（0.1.5〜）：比が1・2・3倍の音は、1チャンネルの波形の「倍音」にします。1つの波形の中の倍音は物理的に1つの音なので、必ず溶け合います。別々のチャンネルにすると、チャンネルごとに16段階の音量が別の時刻に段々に下がり、音が1本ずつ抜けるように聞こえやすいためです（発案者の指摘「各チャンネルの音程の動きが独立して聞こえる」への対策）
- **整数倍でない音だけ別のチャンネルにする**：鐘らしさの元（例：2.4倍）です。同時に鳴る鐘は1つです
- **倍音は時間とともに弱める**：波形を約20ミリ秒ごとに書き換え、高い倍音ほど早く消えるようにします。SCCは音の途中で波形を書き換えられるので、実機でもできる方法です
- **全体の長さで、そろって消す**：音量に「1 −（経過時間 ÷ 全体の長さ）⁴」を掛けます。終わり近くでなめらかに0へ下がり、全チャンネルが全体の長さまでに必ず消えます
- **ずらし（うなり）は既定で0**：わずかな高さの差は、音が揺れる「うなり」になり、音程が動いているように聞こえることがあるため
- **音量を時間で下げる**：SCCの音量は16段階（0〜15）です。指数の形で下がる値を、AudioWorklet の中で約2.7ミリ秒（128サンプル）ごとに整数に丸めて書き込みます
- **SCCの操作だけで作る**：使うのは周波数・音量・キー・波形の書き込みだけです。実機のSCCでも、同じ書き込みをすれば同じ音になる想定です（実機は未確認）

## 設定の値（画面の「設定」欄のJSON）

```json
{ "length": 2.5,
  "partials": [ { "ratio": 1, "level": 14, "decay": 0.9, "cents": 0, "harmonics": [1, 0.5, 0.35], "bright": 0.5 }, ... 5つ ] }
```

| 項目 | 意味 | 範囲 |
| --- | --- | --- |
| `length` | 全体の長さ（秒）。この時間までに必ず全部消える | 0.1〜30 |
| `harmonics` | そのチャンネルの波形の倍音の強さ（1倍・2倍…、最大6つ）。`[1]` なら正弦波 | 各 0〜1 |
| `bright` | 2倍の倍音が約37%になるまでの秒数。k倍の倍音は bright÷(k−1) 秒 | 0.01〜30 |
| `ratio` | 基準の高さに対する比 | 0.125〜16 |
| `level` | 叩いた直後の音量（0なら使わない） | 0〜15 |
| `decay` | 音量が約37%になるまでの秒数 | 0.01〜30 |
| `cents` | 高さのずらし（1/100半音）。うなりを作る | -100〜100 |

## 出発点の音色【想定】

- 小さな鐘（0.1.5〜 既定）：ch1 に 1・2・3倍をまとめ、ch2・ch3 に 2.4倍・4.2倍。全体の長さ2.5秒。C4では約2.3秒で消える（内蔵ブラウザで確認）
- 教会の鐘：比 0.5（2倍の倍音で 1 を含む）・1.2・1.5・2。鐘の音についての一般的な知識による比です。減衰と音量は仮の値です
- 鉄琴風：比 1・2.756・5.404・8.933。両端が自由な棒の振動の比（一般的な知識）

## 分かっている限界

- SCCの周波数の値は整数なので、高い音ほど比がずれます。画面の各行に、実際の高さ（Hz）を出しています
- 音量が16段階なので、消えぎわに段々に下がるのが聞こえる可能性があります（未確認）
- チャンネル4と5は波形を共有します（SCCの仕様）。ch5 の倍音の設定は ch4 にそろえます（画面では変更不可）
- 前の版（0.1.4）の保存した設定は、形が違うので読み込みません
