# 鐘の音の試作（T-201）

本体（`index.html`）とは別のページです：`bell.html`（公開：https://gerupon-lgtm.github.io/SCC/bell.html ）。
発案者が、鐘の音（単音）を別のアプリで使うための試作です。本体のコードは変えていません。

## なぜこの作りか

- **1チャンネルでは作れない**：SCCの1チャンネルは、32点の波形のくり返しです。くり返しの波には、基準の高さの整数倍の音しか含まれません。鐘らしさは、整数倍でない高さの音（例：1.2倍）が混ざることから来るので、チャンネルを重ねます
- **5チャンネルを1つの鐘に使う**：各チャンネルを、決めた比の高さで同時に鳴らします。そのため、同時に鳴る鐘は1つです
- **音量を時間で下げる**：SCCの音量は16段階（0〜15）です。指数の形で下がる値を、AudioWorklet の中で約2.7ミリ秒（128サンプル）ごとに整数に丸めて書き込みます
- **SCCの操作だけで作る**：使うのは周波数・音量・キー・波形の書き込みだけです。実機のSCCでも、同じ書き込みをすれば同じ音になる想定です（実機は未確認）

## 設定の値（画面の「設定」欄のJSON）

```json
{ "wave": "sine",
  "partials": [ { "ratio": 0.5, "level": 9, "decay": 5, "cents": 0 }, ... 5つ ] }
```

| 項目 | 意味 | 範囲 |
| --- | --- | --- |
| `wave` | 波形（全チャンネル共通） | square・saw・triangle・sine・pulse25 |
| `ratio` | 基準の高さに対する比 | 0.125〜16 |
| `level` | 叩いた直後の音量（0なら使わない） | 0〜15 |
| `decay` | 音量が約37%になるまでの秒数 | 0.01〜30 |
| `cents` | 高さのずらし（1/100半音）。うなりを作る | -100〜100 |

## 出発点の音色【想定】

- 教会の鐘：比 0.5・1・1.2・1.5・2。鐘の音についての一般的な知識による比です。減衰と音量は仮の値で、耳での調整が必要です
- 小さな鐘：比 1・2・2.4・3・4.2。仮の値です
- 鉄琴風：比 1・2.756・5.404・8.933。両端が自由な棒の振動の比（一般的な知識）

## 分かっている限界

- SCCの周波数の値は整数なので、高い音ほど比がずれます。画面の各行に、実際の高さ（Hz）を出しています
- 音量が16段階なので、消えぎわに段々に下がるのが聞こえる可能性があります（未確認）
- チャンネル4と5は波形を共有します（SCCの仕様）。この試作は全チャンネル同じ波形なので影響しません
