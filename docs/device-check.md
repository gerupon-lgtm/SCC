## 手順（発案者にお願いすること）

### PC

1. このフォルダで `python -m http.server 8000` を実行し、Chrome で http://localhost:8000 を開く
2. 「▶ 音を出す」を押す。画面の鍵盤を押して、音が出るか聴く（最初は音量0.3）
3. 外部のMIDIキーボードをつなぎ、MIDIの許可を求められたら「許可」。「つながっています」になり、弾くと鳴るか
4. 6音を同時に押して、一番古い音が止まるか。波形のボタンで音色が変わるか
5. 「処理の重さ」の数字を記録する

### Android（Pixel 6a）

1. PCとPixelをUSBでつなぎ、`adb reverse tcp:8000 tcp:8000` を実行
2. Pixel の Chrome で http://localhost:8000 を開く（localhost は安全な接続として扱われる想定。未確認）
3. PCと同じ 2〜5 を行う。USB-MIDIキーボードは、USBハブやOTGアダプター経由でつなぐ
4. 音切れがあれば、そのときの「処理の重さ」と「音切れの疑い」の表示を記録する
